Vibe Center — design directions

Same content in every direction: five agents with mixed presence, a DM with a code reply, two tool calls, a voice exchange, an agent-to-agent relay, a streaming reply and a pending approval; then the same DM during a call (state: waiting for approval). Click an image for full size. The live mocks are the Vite app in this folder (bun run dev); the write-up is in README.md. Round 1 is directions 1–5; round 2 is 6 Nocturne in two variants.

1. Workspace

Slack's three-pane layout, done with care: warm neutrals, Inter, generous row rhythm, a sticky header and call strip, a pushed DM on the phone. Optimises for zero learning curve. Shown in light and dark.

2. Console

A control room for agents: dense, dark, monospace metadata. The sidebar is a live status board with activity sparklines, the DM a timestamped log, tool calls are rows, the call is a channel strip with meters. Optimises for watching several agents at once.

3. Messenger

A phone-first calling app: bubbles, big tap targets, vivid agent colours, a green call strip, and a call that takes the stage as a full-screen sheet with captions and the approval inside it. Optimises for the iPhone and for voice.

4. Editorial

Agents as correspondents: paper tones, Fraunces, a 600px measure, tool calls as marginalia, a thin live ticker for the call, hairlines instead of boxes. Optimises for reading long replies calmly.

5. Pulse

Bold, dark, voice-forward: an icon rail of glowing avatars instead of a sidebar, the header as a capsule that expands into a call island, glass surfaces and one gradient for every primary action. Optimises for presence at a glance and one-thumb use.

6. Nocturne (round 2)

Messenger's structure and calling model (floating call card on desktop, full-screen call sheet on the phone, bottom-anchored composer) with Pulse's collapsible icon-rail sidebar, dialled back to a sleek dark-first language: cool graphite surfaces, hairlines, one quiet indigo accent, glow only on live states. Short turns are bubbles, long agent output is a full-width block.

6b. Nocturne · Ash

The same direction and content on two different axes: warm charcoal surfaces with an ivory, monochrome accent, and no bubbles at all (every turn is a row with a name line). The axes can be recombined.

Round 1 recommendation: Workspace as the base, with Messenger's phone layer (the green call strip, the full-screen call sheet, bottom-anchored composer) and Pulse's presence rings for the sidebar avatars. See README.md for the reasoning. Round 2 follows the user's pick instead: Messenger + Pulse, dialled back, as Nocturne above.
